# 🔥 Horno de Tezontle – Valorización de Bagazo de Agave

> De residuo a recurso: Biochar, CO₂ y energía limpia


## 📌 Resumen ejecutivo

El presente proyecto desarrolla un **prototipo de horno híbrido con aislamiento de tezontle** para procesar **100 kg/día de bagazo de agave**, produciendo biochar como sumidero de carbono y capturando CO₂ mediante absorción química básica.

El horno, una vez validado, podrá ser escalado para tratar residuos sólidos urbanos orgánicos, **prolongando la vida útil de los rellenos sanitarios** al desviar hasta el 40% de los residuos actualmente depositados.

**Impacto esperado:**
- Reducción de emisiones: **18 t CO₂e/año** a escala piloto
- Captura de CO₂: **>85%** mediante solución de NaOH
- Producción de biochar: **20–25 kg/día** (estabiliza carbono >100 años)
- Generación eléctrica: **0.5–1.0 kWh/día** (motor Stirling)
- Prolongación de rellenos sanitarios: **10–15 años adicionales** al desviar orgánicos

El uso de **tezontle como aislante térmico** en el horno reduce costos de importación de materiales refractarios, aporta identidad tecnológica nacional y permite la construcción de un prototipo de muy bajo costo para la valorización de residuos orgánicos.
